# Arun Gyawali Portfolio

## Add your photograph

1. Choose a clear portrait photograph.
2. Crop it vertically or square. Around 1200 x 1200 pixels works well.
3. Rename the image exactly `photo.jpg` (lowercase).
4. Place it in this folder beside `index.html`.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `arungyaw.github.io`.
2. Upload every file from this folder to the repository root. Do not upload the outer folder itself.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait a few minutes, then open `https://arungyaw.github.io`.

Whenever you update the website, replace the changed files in this repository. GitHub Pages redeploys automatically.
